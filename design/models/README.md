# Models

Production 3D assets, generated by script in Blender (`bpy`, the Blender Python module).

```bash
python3 -m venv bl && bl/bin/pip install bpy==5.2.3      # Blender 5.2 LTS as a Python module, Python 3.13
SAMPLES=128 SHOTS=front,profile,low bl/bin/python menpo.py render export
# → /tmp/blend/out/menpo.blend, menpo.glb, menpo_<shot>.png (Cycles)
```

| Asset | Status |
| --- | --- |
| `menpo.py`: menpō with a hinged nose, cheek flanges, cord hooks, a white horsehair moustache, a 3-plate laced throat guard, black lacquer with edge wear and a red lacquer interior | Quality test. Renders in `renders/`. The GLB (about 27 MB with subdivision applied) still needs decimation and texture baking for the web. |
